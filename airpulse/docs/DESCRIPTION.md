# AirPulse

Real-time audience Q&A built natively in Airtable. Let attendees submit and upvote questions, host live sessions with branded presentation mode, and manage everything from one interface — no external tools needed.

---

**AirPulse** is a real-time audience Q&A experience built natively as an Airtable Interface Extension. Designed to replace tools like Slido, AirPulse keeps everything inside your Airtable workspace — no separate accounts, no data silos, no context switching.

**For attendees**, AirPulse provides a clean, focused interface to submit questions and upvote the ones they care about most. The most popular questions rise to the top, and a live "Now Answering" card keeps everyone in sync with what's being discussed right now.

**For hosts and presenters**, AirPulse offers a dedicated admin view to manage the Q&A flow. Pick the next question, mark it as answered, archive low-priority ones, and let the system auto-advance to the top-voted question. A fullscreen presentation mode lets you project the current question on screen with your company branding — gradient or solid backgrounds, custom colors, and your logo.

**For event organizers**, AirPulse includes a setup mode to create and configure events directly from the interface. Set your event name, date, description, brand colors, and toggle it live — all without leaving the page.

## Key Features

- Audience Q&A with real-time upvoting (no race conditions — each vote is its own record)
- Admin panel with Go Live, Mark Answered, Archive, and Restore controls
- Auto-advance to the next top-voted question
- Fullscreen presentation mode with branding
- Per-event theming — primary, secondary, and accent colors sourced from your data
- Primary and secondary logo support with configurable sizing
- Multi-event support with smart event picker
- Setup mode for creating and editing events in-place
- Guided onboarding wizard for first-time configuration
- Full dark mode support
- 20+ custom properties for complete configurability

## How It Works

AirPulse works with three simple tables — Events, Q&A, and Upvotes — and connects to them entirely through custom properties, so it adapts to your existing schema or you can build one from scratch using the built-in schema reference guide.
